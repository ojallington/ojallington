### Oscar Allington

I build software that puts AI agents to work on real systems: agents that know a large
codebase well enough that engineers keep using them, and the checks that say when an agent
is out of its depth. Seven years of backend, data and full-stack work before that.

**Open source**

- **[BoardClaude](https://github.com/ojallington/boardclaude)**: a Claude Code plugin that
  convenes a panel of evaluator agents, scores a project from six perspectives, fixes what
  they find and re-audits to prove the fix. `npx boardclaude install .` ·
  [dashboard](https://boardclaude.vercel.app)
- **[Fix-It Lens](https://github.com/ojallington/fix-it-lens)**: point your phone at an
  appliance and repair it from its own manual. The model proposes; code checks every quote
  against its page and enforces the safety rules. [Watch it work](https://youtu.be/82TwKP4tkw4).

**How I like to build:** the model proposes, code decides; an agent should say what it
doesn't know; ship with tests and a demo anyone can run.
